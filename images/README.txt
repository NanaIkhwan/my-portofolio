PANDUAN GAMBAR PORTOFOLIO
==========================

Letakkan file gambarmu di folder ini dengan nama berikut:

  profile.jpg     → Foto profil kamu (rasio 3:4 atau 1:1, min. 600px)
  project-1.jpg   → Thumbnail Proyek 1 (Aplikasi E-Learning)
  project-2.jpg   → Thumbnail Proyek 2 (FinTrack)
  project-3.jpg   → Thumbnail Proyek 3 (Urban Portraits)
  project-4.jpg   → Thumbnail Proyek 4 (Website UMKM Batik)
  project-5.jpg   → Thumbnail Proyek 5 (FoodNow)
  project-6.jpg   → Thumbnail Proyek 6 (Nature & Landscape)

Format yang didukung: .jpg .jpeg .png .webp
Ukuran thumbnail proyek yang disarankan: 800x500px (rasio 16:10)

Bisa juga pakai URL langsung, contoh di index.html:
  src="https://i.imgur.com/namafile.jpg"
  src="https://drive.google.com/uc?id=FILEID"

Jika gambar tidak ditemukan, otomatis tampil placeholder mockup.
